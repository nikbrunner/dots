# Triage labels

| Role              | Tracker label     | Meaning                          |
| ----------------- | ----------------- | -------------------------------- |
| `needs-triage`    | `needs-triage`    | Needs maintainer evaluation      |
| `needs-info`      | `needs-info`      | Waiting on reporter information  |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation    |
| `wontfix`         | `wontfix`         | Will not be actioned             |

When a skill names a triage role, use its tracker label from this table.
